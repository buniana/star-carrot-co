# 🥕 星际萝卜公司 · Star Carrot Co.

一个 3D 可爱风的单机经营小游戏：在一颗低重力（0.3G）的星球上种星际萝卜，送上流水线榨汁、装箱、包装，再通过公司总部前台接网页和电话订单。

## 怎么运行

推荐用自带的小后端启动（只用 Python 3 标准库，不用装任何东西）：

```bash
python3 server.py            # 打开 http://localhost:8765
```

后端提供存档同步和银河排行榜。也可以直接用浏览器打开 `index.html`，这时存档只保存在浏览器本地，没有排行榜。（都需要联网加载 three.js 和字体。）

## 开场动画

打开游戏会先出现开场动画（`assets/intro.mp4`，61 秒）：点「▶ 播放开场动画」观看，或点「跳过」直接进入开始界面；播放中按 `Esc` / `Enter` / `空格` 也能跳过。

内容：复古霓虹电视开机 → 彩条和雪花后出现公司 logo → 机器人小星播报星际萝卜新闻（萝卜汁、礼盒上新）→ 广告：大萝卜跳舞并分成三根 → 小社长登场 → 芭蕾舞访客旋转出场 → 印着 logo 的巨型火箭贴着镜头飞过，飞向星际萝卜农场 → 游戏开始。播报配音为 AI 合成。

## 玩法

- 🌱 **星际农场**：种萝卜 → 长大发光 → 收获（+3 🥕）
- 🧃 **榨汁机**：2 🥕 → 1 瓶萝卜汁；🧺 **装箱台**：3 🥕 → 1 箱萝卜
- 🍬 **软糖机** / 🍰 **烘焙炉** / 🍦 **冰淇淋机**：研发解锁的萝卜新产品（2 / 4 / 5 🥕，售价 10 / 20 / 28 ⭐）
- 🎀 **包装机**：商品停在包装机下，按 E 包装，越快越“完美”
- 🚀 **货运火箭**：发射卖出包装好的商品
- 🏢 **公司总部前台**：机器人接待员小星帮你接 📞 电话订单和 🌐 网页订单，在前台交付
- 🩰 **芭蕾舞访客**：送她想要的商品，双倍报酬

## 存档

- **自动存档**：研发成功、交付订单、火箭发射、离开页面时自动保存（两次至少间隔 30 秒；没有重要节点时最多 5 分钟存一次）
- **手动存档**：暂停菜单里点「💾 手动保存」，和自动存档分开放，互不覆盖
- 开始界面和暂停菜单都可以选择读取哪一个
- 后端把存档放在 `saves/` 目录（已加入 `.gitignore`）
