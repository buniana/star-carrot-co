# 🥕 星际萝卜公司 · Star Carrot Co.

一个 3D 可爱风的单机经营小游戏：在一颗低重力（0.3G）的星球上种星际萝卜，送上流水线榨汁、装箱、包装，再通过公司总部前台接网页和电话订单。

## 怎么玩

直接用浏览器打开 `index.html` 即可（需要联网加载 three.js 和字体）。

| 操作 | 键位 |
| --- | --- |
| 走路 | `WASD` / 方向键（手机：左下摇杆） |
| 冲刺 | `Shift`（手机：摇杆推到底） |
| 低重力跳跃 | `空格` |
| 互动 | `E` |
| 转视角 | 拖动鼠标 / 触控板左右划 |
| 缩放 | 滚轮 / 触控板双指捏合 |

## 玩法

- 🌱 **星际农场**：种萝卜 → 长大发光 → 收获（+3 🥕）
- 🧃 **榨汁机**：2 🥕 → 1 瓶萝卜汁；🧺 **装箱台**：3 🥕 → 1 箱萝卜
- 🎀 **包装机**：商品停在包装机下，按 E 包装，越快越“完美”
- 🚀 **货运火箭**：发射卖出包装好的商品
- 🏢 **公司总部前台**：机器人接待员小星帮你接 📞 电话订单和 🌐 网页订单，在前台交付
- 🩰 **芭蕾舞访客**：送她想要的商品，双倍报酬

## 角色

- **主角**：橘红色双马尾小女孩，粉色双球头绳、雀斑、小熊发卡、米色围巾、绿格纹背带裤、蓝色小鞋，宠物小兔子
- **芭蕾舞访客**：金色双丸子头、粉色梅花头箍、粉色芭蕾裙和绑带舞鞋、小兔发卡、粉色菱格包，宠物小猫
- **前台小星**：戴耳麦的机器人接待员

## 技术

单个 HTML 文件，three.js r128 + Web Audio（背景音乐和音效都是代码实时合成的，没有音频文件）。
